【本週重大更新摘要與資安重點】
--------------------------------------------------------------------------------
1. 🛡️ 【關鍵資安防護】自動套用 PHP2Shell (CVE-2024-4577) 漏洞緩解
   - Apache 服務自動注入軟連字號 (%AD) 參數注入攔截規則，直接回傳 HTTP 403。
   - 針對靜態與匯出目錄（www/assets、www/export）強制禁止執行任何後端腳本。
   - PHP 環境強制關閉 expose_php、allow_url_include 等機敏設定。

2. 🚀 【後端雙軌現代化】PHP 8.5 FastCGI 服務全量就緒 (Port 8085)
   - 完成登記、測量、地政業務、排程統計、檔案匯出入等 4 大批次全量 API 移植。
   - 與 PHP 7.4 舊版雙軌並行轉發，大幅提升運算效能並具備零停機切換能力。

3. 🛠️ 【自動維運管線】5 階段主機環境配置與連接埠健康驗證
   - 自動配置 Apache2.4、PHP 7.4、PHP 8.5、Node.js 綠色環境與 PM2 原生服務。
   - 徹底修復 pm2-logrotate 離線安裝問題與非管理者 CMD 執行權限衝突。

4. 💬 【即時通訊全面升級】桌面端遷移至 Tauri v2 架構 (v1.6.0)
   - 體積大幅縮減，記憶體占用減半，支援 NSIS 全自動靜默安裝。
   - 前端與桌面端同步支援「最近 10 筆輸入訊息記憶」與私訊跨頻道狀態即時連動。

【各子系統詳細更新歷程】
================================================================================

■ 1. 自動更新與維運工具 (LAH-Updater v1.6.1 ～ v1.6.6)
--------------------------------------------------------------------------------
  ● [資安] 自動套用 CVE-2024-4577 防護，並啟用 5 大必備 PHP 擴充模組
    - 自動啟用 gd2/gd, ldap, imap, pdo_sqlite, sqlite3 模組。
    - Apache mod_php7 自動預載 libsasl.dll 等 8 個核心動態函式庫，確保 LDAP 正常運作。
  ● [管線] 5 階段自動化安裝與收尾管線
    - 階段 1：建立 Apache 服務並校正 PHP 7.4 mod_php 與路徑。
    - 階段 2：建立 PHP 8.5 FastCGI API Proxy (Port 8085) 並由 PM2 守護。
    - 階段 3：套用資安加固並執行 httpd.exe -t 語法驗證。
    - 階段 4：本機綠色版 Node.js 與 PM2 核心自動綁定，配置開機自啟服務。
    - 階段 5：全系統服務啟動與監聽埠健康巡檢 (Port 80, 8085, 8080, 8081/8082)。
  ● [維運] 綠色 Node.js 與 PM2 離線安裝及 IPC 權限修復
    - PM2 通訊由具權限隔離的 Named Pipe 改為 Loopback TCP (127.0.0.1:42681/42682)。
    - 一般使用者於 CMD 視窗執行 pm2 ls 不再發生 connect EPERM 權限錯誤。
    - 內建 pm2-logrotate Windows 本機離線修補，100% 離線秒級安裝。
  ● [備份] 移除工具 (uninstaller.py) 獨立備份與備份範圍擴充
    - 新增「立即備份重要資料」獨立按鈕，支援自訂路徑存檔。
    - 擴充備份範圍涵蓋 www/assets/* 檔案與 .pm2 設定狀態。
    - updater.py 支援自動搜尋 _LAH_Backup_*.zip 並一鍵精準還原。
  ● [介面] 左右雙欄對稱排版重構
    - 修復 Node.js 執行環境卡片垂直擠壓問題，操作按鈕版面整齊劃一。
    - 未偵測到之更新包預設隱藏，支援勾選動態展開。
  ● [打包] pack.py 支援全系統 7 大更新包規格，整合進度條與 PHP8 API 打包。

■ 2. 業務核心後端 API (LAH-API)
--------------------------------------------------------------------------------
  ● [架構] PHP 8.5 雙軌架構完成移植 (目錄對齊 C:\AppServ\API，監聽 Port 8085)
    - Batch 1：使用者認證、系統通知、權限管理與通訊模組。
    - Batch 2：登記、測量、地價、公文與地政核心業務類別。
    - Batch 3：排程監控、快取清除、統計圖表與營運報表。
    - Batch 4：Excel 匯出入、影像處理與檔案串流模組。
  ● [測試] 全量補齊 72 個核心業務類別自動化單元測試，提供批次驗證腳本。
  ● [資安] 禁用 Apache 目錄瀏覽 (Options -Indexes)，強化機敏檔案目錄保護。
  ● [網域] 新增 Active Directory (AD) 伺服器動態探針、快取與可用性狀態 API。

■ 3. 智慧管控系統前端 (LAH-FE)
--------------------------------------------------------------------------------
  ● [控制] 新增 PHP 8.5 雙軌 API 切換控制面板，對齊 8085 服務埠號。
  ● [業務] 地籍異動即時通與住址隱匿功能優化
    - 表格新增收件人員動態篩選下拉選單與頭像顯示。
    - 調整隨案標籤樣式為 info 視覺樣式，表格預設顯示 15 筆。
    - 修復簡訊選單被遮截與彈出視窗剪貼簿複製問題。
  ● [即時通] 內嵌即時通元件升級 (components/lah-messenger-*.vue)
    - 輸入框記憶最近 10 筆已發送訊息，提供快捷選單預覽。
    - 修正編輯公告與即時訊息時 HTML 實體編碼未反轉義問題。
    - 私訊編輯與刪除支援跨頻道即時連動與發送鏡像備份。
  ● [功能] 移植所內自訂書籤索引；登記逾期案件統計圖表本地彈窗；首頁監控入口卡片。

■ 4. 即時通訊伺服器 (lah-messenger-server)
--------------------------------------------------------------------------------
  ● [同步] 伺服器端同步更新私訊接收端頻道資料庫，廣播雙端連線 ACK。
  ● [防護] 強化附件上傳副檔名與型態防呆驗證，提供詳細錯誤回報。
  ● [穩定] 增加 AD 服務離線平滑降級與本地身分快取解析機制。
  ● [維護] 首頁模組化重構與子元件拆分，提升服務端載入效能。

■ 5. 桃園即時通桌面客戶端 (lah-messenger)
--------------------------------------------------------------------------------
  ● [架構] 全面遷移至 Tauri v2 架構 (v1.6.0)
    - 程式體積顯著縮減，降低系統資源開銷。
    - 支援 Windows NSIS 全自動安裝程式，簡化部署程序。
  ● [功能] 輸入框記憶最近 10 筆已送出訊息與快速選單。
  ● [修復] 修正訊息中本機與網路磁碟路徑解析，支援 Windows 檔案總管精準開啟。

■ 6. 工作區本機開發與維運快捷腳本 (LAH-Workspace)
--------------------------------------------------------------------------------
  ● start_dev.bat：整合 PHP 8.5 FastCGI 啟動，支援全服務埠號占用偵測與防重啟。
  ● stop_dev.bat：強化 PM2 守護進程安全保護，依序安全釋放佔用埠號。
  ● git-pull.bat：提供一鍵依序更新根目錄及所有子專案最新原始碼。
  ● 新增全域跨專案實機驗證技能 (verify-lah)。

【管理師部署注意事項】
================================================================================
1. 執行更新前建議：
   - 於更新工具首頁確認「執行前自動備份重要資料」已勾選，或使用移除工具的
     「立即備份重要資料」手動產出備份檔 (_LAH_Backup_YYYYMMDD_HHMMSS.zip)。
2. 更新後驗證：
   - 更新完成後請留意彈出之「連接埠健康巡檢報告」：
     * Port 80   (Apache2.4 網頁服務)  ➔ 必須為 [OK]
     * Port 8085 (PHP 8.5 FastCGI 核心) ➔ 必須為 [OK]
     * Port 8080 (LAH-FE 前端系統)     ➔ 必須為 [OK]
     * Port 8081 (即時通 WebSocket 埠)  ➔ 必須為 [OK]
     * Port 8082 (即時通 HTTP 附件埠)   ➔ 必須為 [OK]
3. 若遇問題可隨時利用「備份設定還原」一鍵回復原始組態。
