【本週重大更新摘要與資安重點】
--------------------------------------------------------------------------------
1. 🛡️ 【關鍵資安防護擴充】全面防堵 PHP2Shell (CVE-2024-4577) 與 WebShell
   - Apache 服務自動注入軟連字號 (%AD) 參數注入攔截規則，直接回傳 HTTP 403。
   - 擴大目錄禁執行防護至 www/assets、www/export、www/import 與 www/uploads。
   - 阻斷對 www/log 目錄的直接存取，嚴禁執行任何後端腳本檔案。
   - PHP 設定檔全面掃描並清除 auto_prepend_file 與 auto_append_file 惡意植入。
   - PHP 環境強制關閉 expose_php、allow_url_include、enable_dl 等機敏設定。

2. 🦀 【維運三件套全面升級】維運工具遷移至 Tauri 2 (Rust) 核心架構
   - 自動更新 (updater)、自動備份 (backuper) 與自動移除 (uninstaller) 獨立拆分。
   - 程式體積縮減至 10~11 MB，達成隨點秒開並大幅降低防毒軟體誤判率。
   - 繪製專屬立體視覺圖示（更新：翡翠綠、備份：科技藍、移除：警戒紅）。
   - 產出執行檔統一輸出至專案根目錄 dist/。

3. 📦 【核心資料庫驅動備份】自動備份工具 (backuper) 納入 OCI8 與 MSSQL
   - 擴充備份項目支援 instantclient_11_2 資料夾整包備份，保障 Oracle 9i 連線環境。
   - 自動動態掃描並備份 php7/ext 與 php85/ext 底下之 php_oci8*.dll 與 sqlsrv 擴充。
   - 備份還原日誌區塊改為彈現式對話框 (Modal Overlay)，維持主畫面緊湊無捲軸。

4. 🟢 【PM2 守護與通訊修復】Loopback TCP 通訊與 100% 離線安裝
   - PM2 通訊由 Named Pipe 改為 Loopback TCP (127.0.0.1:42681/42682)。
   - 徹底解決非管理者權限 CMD 視窗執行 pm2 指令時發生 connect EPERM 錯誤。
   - 內建 pm2-logrotate 離線修補機制，無對外網路環境亦可秒級安裝。
   - 新增「自動註冊 PM2 Windows 原生系統服務」勾選項與即時狀態偵測。

5. 🚀 【後端雙軌現代化】PHP 8.5 FastCGI 服務全量就緒 (Port 8085)
   - 完成登記、測量、地政業務、排程統計、檔案匯出入等 4 大批次全量 API 移植。
   - 與 PHP 7.4 舊版雙軌並行轉發，具備高運算效能與零停機切換能力。
   - 補齊 20 支以上核心業務 API 之全路徑自動化單元與整合測試。

6. 💬 【即時通訊全面升級】桌面端支援 WiX MSI 企業級安裝包
   - 桃園即時通桌面端遷移至 Tauri v2 架構 (v1.6.0)，體積縮減且記憶體占用減半。
   - 支援 Windows NSIS 與 WiX MSI 靜默安裝，並完善離線 WebView2 執行期配置。
   - 前端與桌面端同步支援「最近 10 筆輸入訊息記憶」與私訊跨頻道狀態即時連動。

【各子系統詳細更新歷程】
================================================================================

■ 1. 自動更新與維運工具 (LAH-Updater v1.6.1 ～ v1.7.0)
--------------------------------------------------------------------------------
  ● [架構] 維運工具全量改寫為 Tauri 2 (Rust) 核心架構
    - 以 Rust + 輕量前端實作，擺脫 Python 與 PyInstaller 解壓開銷，啟動小於 0.3 秒。
    - 拆分為獨立維運三件套：自動更新 (updater/)、自動移除 (uninstaller/)、自動備份 (backuper/)。
    - 重新設計專屬圖示：更新工具（深翡翠綠）、備份工具（科技深藍）、移除工具（警戒深紅）。
    - 執行檔統一輸出至專案根目錄 dist/，並提供根目錄一鍵建置批次檔。
  ● [資安] 整合 PHP2Shell (CVE-2024-4577) 緩解與擴大防護範圍 (v1.6.8)
    - Apache httpd.conf 自動注入 Query String 軟連字號 (%AD) 阻斷規則。
    - 禁執行腳本目錄擴充至 www/assets、www/export、www/import、www/uploads，並阻斷 www/log 存取。
    - php.ini 自動清除潛在被惡意植入的 auto_prepend_file 與 auto_append_file 指令。
    - 一鍵資安強化按鈕與更新管線完整串聯，語法驗證通過後自動安全重啟服務。
  ● [備份] backuper (自動備份與還原工具) 重大升級
    - 擴充備份範圍：整包備份 instantclient_11_2 資料夾與 php7/ext、php85/ext 之 OCI8/MSSQL DLL。
    - 還原防護機制：還原前自動建立 restore_undo_<時間戳記>.zip 還原點，具備防 Zip Slip 檢查。
    - 介面空間最佳化：執行進度與日誌改由彈現式對話框呈現，主畫面無垂直捲軸。
  ● [維運] 綠色 Node.js 與 PM2 離線安裝、TCP IPC 與開機服務註冊
    - PM2 通訊機制改採 Loopback TCP (127.0.0.1:42681/42682)，徹底修復 connect EPERM 權限錯誤。
    - 內建 pm2-logrotate Windows 離線修補，支援無外網離線秒級安裝。
    - 新增「自動註冊 PM2 開機系統服務」選項，支援狀態即時偵測與 WinSW 服務管理。
  ● [管線] 5 階段自動化安裝與多重防呆自癒
    - 階段 1：建立 Apache 服務並校正 PHP 7.4 mod_php 與路徑。
    - 階段 2：建立 PHP 8.5 FastCGI API Proxy (Port 8085) 並由 PM2 守護。
    - 階段 3：套用資安強化設定並執行 httpd.exe -t 語法驗證。
    - 階段 4：本機綠色版 Node.js 與 PM2 核心自動綁定，配置開機自啟服務。
    - 階段 5：全系統服務啟動與監聽埠健康巡檢 (Port 80, 8085, 8080, 8081/8082)。
    - 自動攤平 Apache24/Apache24 雙層巢狀目錄，防止解壓路徑層級錯誤。
    - 修正 Apache httpd.conf 條件變數重複百分比符號語法問題。
  ● [介面] 視窗佈局調整與即時套用按鈕
    - 視窗高度調整為 720px，新增底部固定吸附控制列。
    - 新增「⚡ 立即套用系統服務設定與資安強化配置」獨立快捷按鈕。
    - 打包工具 pack.py 支援全系統 7 大更新包規格，具備動態根目錄探測能力。

■ 2. 業務核心後端 API (LAH-API)
--------------------------------------------------------------------------------
  ● [架構] PHP 8.5 雙軌架構完成移植 (目錄對齊 C:\AppServ\API，監聽 Port 8085)
    - Batch 1：使用者認證、系統通知、權限管理與通訊模組。
    - Batch 2：登記、測量、地價、公文與地政核心業務類別。
    - Batch 3：排程監控、快取清除、統計圖表與營運報表。
    - Batch 4：Excel 匯出入、影像處理與檔案串流模組。
  ● [測試] 補齊 20 支以上核心 API 之全路徑自動化單元與整合測試
    - 涵蓋 prefetch_json_api、notification_json_api、myquery_json_api、mssql_json_api 等端點。
    - 驗證並修正 PHP 8.5 相容性、字串內插邊界與減號筆誤語法缺陷。
  ● [資安] 擴充 Apache 參考設定檔 (httpd.conf-ref)
    - 禁用 Apache 目錄瀏覽 (Options -Indexes)。
    - 擴充 PHP2Shell 與 WebShell 防護範圍至 www/import、www/uploads 與 www/log 目錄。
  ● [網域] 新增 Active Directory (AD) 伺服器動態探針、快取與可用性狀態 API。

■ 3. 智慧管控系統前端 (LAH-FE)
--------------------------------------------------------------------------------
  ● [控制] 新增 PHP 8.5 雙軌 API 切換控制面板，對齊 8085 服務埠號。
  ● [業務] 地籍異動即時通與住址隱匿功能優化
    - 表格新增收件人員動態篩選下拉選單與頭像顯示。
    - 調整隨案標籤樣式為 info 視覺樣式，表格預設顯示 15 筆。
    - 修復簡訊選單被遮截與彈出視窗剪貼簿複製問題。
  ● [即時通] 內嵌即時通元件升級 (components/lah-messenger-*.vue)
    - 輸入框記憶最近 10 筆已發送訊息，提供快捷選單預覽。
    - 修正編輯公告與即時訊息時 HTML 實體編碼未反轉義問題。
    - 私訊編輯與刪除支援跨頻道即時連動與發送鏡像備份。
  ● [功能] 移植所內自訂書籤索引；登記逾期案件統計圖表本地彈窗；首頁監控入口卡片。
  ● [網域] 增加 AD 服務可用性響應與無效營運介面動態隱藏。

■ 4. 即時通訊伺服器 (lah-messenger-server)
--------------------------------------------------------------------------------
  ● [同步] 伺服器端同步更新私訊接收端頻道資料庫，廣播雙端連線 ACK。
  ● [防護] 強化附件上傳副檔名與型態防呆驗證，提供詳細錯誤回報。
  ● [穩定] 增加 AD 服務離線平滑降級與本地身分快取解析機制。
  ● [維護] 首頁模組化重構與子元件拆分，提升服務端載入效能。

■ 5. 桃園即時通桌面客戶端 (lah-messenger)
--------------------------------------------------------------------------------
  ● [架構] 全面遷移至 Tauri v2 架構 (v1.6.0)
    - 程式體積顯著縮減，降低系統資源開銷。
    - 支援 Windows NSIS 全自動安裝程式，簡化部署程序。
    - 新增支援 Windows WiX MSI 企業級安裝包產出。
    - 完善離線 WebView2 執行期配置，相容無對外網路部署環境。
  ● [功能] 輸入框記憶最近 10 筆已送出訊息與快速選單。
  ● [修復] 修正訊息中本機與網路磁碟路徑解析，支援 Windows 檔案總管精準開啟。

■ 6. 工作區本機開發與維運快捷腳本 (LAH-Workspace)
--------------------------------------------------------------------------------
  ● start_dev.bat：整合 PHP 8.5 FastCGI 啟動，支援全服務埠號占用偵測與防重啟。
  ● stop_dev.bat：強化 PM2 守護進程安全保護，依序安全釋放佔用埠號。
  ● git-pull.bat：提供一鍵依序更新根目錄及所有子專案最新原始碼。
  ● 新增全域跨專案實機驗證技能 (verify-lah)。
  ● 更新個人工作模式技能 (pyliu-mode) 以涵蓋雙軌同步與分層治理慣例。

【管理師部署注意事項】
================================================================================
1. 執行更新前建議：
   - 建議於更新前先執行「智慧控管與監控系統 - 備份與還原工具 (backuper)」產出完整備份檔
     (_LAH_Backup_YYYYMMDD_HHMMSS.zip)，現已自動涵蓋 Oracle instantclient 與資料庫 DLL。
2. 更新後驗證：
   - 更新完成後請留意彈出之「連接埠健康巡檢報告」：
     * Port 80   (Apache2.4 網頁服務)  ➔ 必須為 [OK]
     * Port 8085 (PHP 8.5 FastCGI 核心) ➔ 必須為 [OK]
     * Port 8080 (LAH-FE 前端系統)     ➔ 必須為 [OK]
     * Port 8081 (即時通 WebSocket 埠)  ➔ 必須為 [OK]
     * Port 8082 (即時通 HTTP 附件埠)   ➔ 必須為 [OK]
3. 若需調整設定或還原：
   - 可利用更新工具首頁之「⚡ 立即套用系統服務設定與資安強化配置」即時套用服務與資安規則。
   - 若遇設定異常，可隨時透過 backuper 一鍵還原原始組態。
