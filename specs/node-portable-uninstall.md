# Node 沙盒移除功能

## 已確認需求

在 node-portable 控制台加入 **移除安裝**。入口不依賴工具旁是否存在 `base/node.zip`。

使用者先檢視目標目錄、將停止的程序、解除的服務，以及移除與保留清單，再按 **確認移除**。取消或預覽失敗時不得修改沙盒。

移除範圍為選定根目錄的 Node／PM2 執行環境、屬於該目錄的 `PM2_Portable_Service`，以及工具產生的 `lah-cmd.bat`。停止該環境的程序與子程序後，才能刪除檔案。

保留受管應用程式、業務資料、`.pm2` 既有快照與設定、所有既有日誌、備份、安裝包及駐留工具執行檔。移除不自動執行 `pm2 save`。重裝後可還原既有快照。

若其他服務（包括 `LAH_PM2_Service`）共用目標 Node 或 `.pm2`，必須阻擋移除。不得移除其他服務、終止其他目錄的 Node／PM2、修改全域環境變數，或執行既有全機清理函式。

預覽須能在服務與應用運行時直接開啟，等待既有狀態查詢完成。後端必須重新驗證固定移除範圍，並依最新盤點停止程序。短暫 CLI 結束、應用重新啟動等程序清單變動，不視為移除範圍變更。目錄含 Junction／符號連結、服務實體路徑不符、程序身分無法確認、缺少管理員權限，或停止服務／程序失敗時，必須拒絕或中止移除。部分完成也不得回報成功。

## 驗證方式

- Rust 測試使用隔離目錄，驗證保留資料、服務衝突、失敗中止、預覽變更、程序隔離及 Junction 拒絕。
- 原生程序測試只啟動與停止測試自己的程序，不變動本機既有 Windows 服務。
- 瀏覽器載入實際 HTML／JS，以替代的 Tauri 傳輸回應驗證入口、取消、確認、失敗訊息與各視窗尺寸；不將這項驗證宣稱為實際服務解除安裝測試。

不涉及 HTTP API、WebSocket、SQLite 或 Oracle 契約。不在開發機實際移除現有沙盒，不發布正式產物。
