⌨️ 沙盒終端常用指令速查 (CLI Cheat Sheet)
點擊上方【💻 沙盒終端】開啟專屬視窗後，可隨時執行以下命令：
pm2 list 檢視所有受管業務進程清單、PID、記憶體與運作狀態
pm2 restart <name|all> 重新啟動指定的業務進程（或輸入 all 全部重啟）
pm2 logs <name> --lines 50 即時滾動檢視指定進程最後 50 行標準輸出與錯誤日誌
pm2 save 固化當前運作進程快照，確保開機或重啟服務後自動復原
pm2 reloadLogs 強制 PM2 重新打開日誌指標，即刻釋放已輪替歷史日誌
📋 核心守護機制與維運 SOP (Operational FAQ)
Node 可攜沙盒環境標準日常維護與狀態防護守則：
  • 改動程式後請固化狀態：更新應用程式代碼、修補參數或變更進程後，務必點擊上方【💾 儲存快照】（pm2 save），避免伺服器重啟時遺失變更。
  • 60 秒常駐守護與自癒：背景服務具備定期偵測機制，若偵測到 PM2 程序解譯器異常搶佔，會自動強制自癒並以沙盒可攜 Node 重啟。
  • 日誌容量定期釋放：日誌由 pm2-logrotate 自動以 Gzip 壓縮，若遇進程密集輸出，可隨時點擊【🗜️ 立即壓縮輪替】即刻釋放硬碟空間。
  • 資安合規佐證：右上角【🛡️ 資安自檢】已支援動態受管服務識別，檢測完成後將於 logs\ 匯出合格佐證報告供稽核備查。
