# 智慧控管與監控系統 - 管理儀表板 (LAH-Dashboard)

本工具為 LAH 智慧控管系統之專屬單一執行檔原生監控與維運儀表板，基於 **Tauri 2 (Rust) + 純原生 HTML/CSS/JS + xterm.js 離線引擎** 架構實作，可直接放置於伺服器安裝根目錄（`C:\AppServ\` 或 `D:\AppServ\`）隨點即開。

---

## 1. 核心功能與視圖架構

### 1.1 頂部全域控制列
- **一鍵全域重啟與脈衝輪詢**：提供防呆確認之一鍵重啟全部服務（Apache 2.4 與所有 PM2 守護進程）；觸發後自動啟動高頻脈衝輪詢（Burst Polling），在介面上即時反饋各進程由「重啟中...」至「在線」之狀態跳轉。
- **動態輪詢間隔與暫停**：支援 1秒、3秒、5秒、10秒、30秒 自由切換或手動暫停輪詢，防止非必要背景負載。
- **全域字級與深淺色主題**：內建全域字級基礎放大 20%，並支援一般、中（+15%）、大（+25%）彈性切換；提供沉浸深色與高對比明亮主題。

### 1.2 服務監控與控制（分頁一）
- **雙軌分層控管**：
  - **Windows 系統服務層**：管控 `LAH_Web_Service`（Apache 2.4 反向代理）與 `LAH_PM2_Service`（PM2 Daemon 守護進程）。
  - **PM2 應用進程層**：管控 `pm2-logrotate`（日誌輪替）、`LAH-WSS`（即時通訊 Port 8081/8082）、`LAH-FE`（智慧管控前端網站 Port 8080）、`LAH-SCHEDULER`（排程引擎）與 `lah-api-v85`（PHP 8.5 FastCGI 核心 Port 8085）。
- **個別操作**：支援個別啟動、停止、重新啟動，並即時反映 CPU、記憶體占用與重啟計數。

### 1.3 即時日誌檢視器（分頁二）
- **全模組日誌自動探測**：涵蓋前端網站、即時通訊、排程引擎、PHP 8.5、LAH-API 核心業務日誌（`www\log`）、Apache（error/access）、WinSW wrapper 包裝日誌與 pm2-logrotate 運作紀錄。
- **動態串流追蹤**：支援 Auto-Tail 即時追蹤、關鍵字即時篩選、清空畫布與「以 Windows 記事本開啟」實體檔案。

### 1.4 系統指標與快捷維運（分頁三）
- **四大核心 KPI 卡片水平對齊**：
  - **CPU 總使用率**：動態多核心即時負載數值與 60 秒負載折線圖。
  - **系統實體記憶體**：即時實體記憶體消耗量、使用佔比與負載折線圖。
  - **網路即時流量**：26px 醒目總流量大數字，副標題以青藍（接收）與橘黃（傳送）彩色呈現雙向波動明細，底部折線圖精確貼齊下緣。
  - **安裝磁碟剩餘空間**：剩餘 GB 容量大數字與已用佔比，搭配水平齊平之狀態進度條（與其餘三張 KPI 卡片水平邊界完美對稱）。
- **LAH 服務群組記憶體占用排名**：精準彙總 Apache 與 PM2 各子進程之記憶體消耗，採單排直立微型卡水平滾動呈現。
- **五大關鍵連接埠健康探針**：五大關鍵通訊埠（Port 80, 8080, 8081, 8082, 8085）即時 TCP 心跳探測與監聽狀態徽章。
- **快捷維運工具箱**：
  - 一鍵啟動 `lah-cmd.bat` 私有隔離沙盒維運終端
  - 瀏覽器開啟前端系統入口（`http://127.0.0.1:8080/`）
  - Apache 組態語法校驗（執行 `httpd.exe -t`）
  - 手動觸發日誌壓縮輪替（`pm2-logrotate`）釋放磁碟空間
  - 開啟日誌存放目錄（`AppServ\logs\`）

### 1.5 核心組態編輯器（分頁四）
- **支援十一組核心關鍵組態快速切換**：
  - Apache 核心組態 (`httpd.conf`)
  - Apache 虛擬主機 (`httpd-vhosts.conf`)
  - PHP 7.3 組態 (`php.ini`)
  - PHP 8.5 組態 (`php.ini`)
  - 後端 API 環境變數 (`www/.env`)
  - 前端網站環境變數 (`LAH-NUXTJS/.env`)
  - 即時通訊伺服器環境變數 (`.env`)
  - LAH-API 核心環境變數 (`.env`)
  - PM2 前端與排程進程組態 (`LAH-NUXTJS/ecosystem.config.js`)
  - PM2 即時通訊進程組態 (`lah-messenger-server/ecosystem.config.js`)
  - PM2 API FastCGI 進程組態 (`LAH-API/ecosystem.config.js`)
- **單排緊湊工具列**：採強制單排併列設計（`flex-wrap: nowrap`），組態下拉選單彈性自適應寬度，儲存、歷史還原、記事本開啟與換行切換按鈕維持抗壓縮，釋放最大縱向編輯視野。
- **自訂檔案挑選**：支援開啟伺服器任意自訂組態或文字檔。
- **安全防護機制**：
  - 自動時間戳備份（儲存前自動於 `backups/` 建立備份副本）
  - 歷史備份一鍵還原下拉選單
  - Apache 組態語法自動預檢（執行 `httpd.exe -t`，若未通過立即警示並提供一鍵自動撤銷還原）
  - PM2 進程組態語法自動預檢（執行 `node -c`，儲存前嚴格校驗 JavaScript 語法，防止語法錯誤造成進程異常離線）
  - 關聯服務精確分流重啟提示（儲存後依組態類型分流提示重啟 Apache、個別 PM2 進程或全域服務）
- **雙欄範本即時比對**：
  - 開啟具有範本之檔案（如 `www/.env`、`LAH-NUXTJS/.env`）時，自動展開雙欄對照視窗並即時載入 `.env.example` 完整註解與設定範本。
  - 支援「📋 複製範本」、「📥 套用至編輯區」與一鍵切換收合。

### 1.6 沙盒終端機（分頁五）
- **純離線 xterm.js 專業虛擬終端**：100% 離線靜態資源（零外部 CDN），支援 VT100 / ANSI 256 色真彩渲染與表格精確定位。
- **直接鍵盤流暢互動**：直接於畫面上打字鍵入指令，支援 Backspace 退格、↑/↓ 瀏覽歷史命令、Ctrl+C 中斷與滑鼠反白複製貼上。
- **雙向聯動編碼切換**：提供「UTF-8 (Unicode)」與「CP950 (Big5 繁體中文)」即時切換選單，後端透過 Windows 原生 API 進行解碼分流，並自動發送 `chcp` 代碼頁同步指令，徹底根除中文亂碼。
- **常用指令快捷工具列**：一鍵執行 `pm2 status`、`pm2 restart all`、`httpd -t`、`版本檢查`、`git status`、`檢查 Port 80`。

## 2. 編譯與建置指令

### 一鍵編譯發布
```powershell
python tools/dashboard/build.py
# 或於 LAH-Updater 根目錄執行：
.\建立管理儀表板工具.bat
```

產出執行檔將自動發布至：
- `LAH-Updater/dist/智慧控管與監控系統 - 管理儀表板.exe`
- 若偵測到本機存在 `C:\AppServ`，將同步部署至 `C:\AppServ\智慧控管與監控系統 - 管理儀表板.exe`。
